# Calculadora en Python

## Descripción

Este proyecto consiste en una calculadora desarrollada en Python que permite realizar diferentes operaciones matemáticas mediante un menú interactivo en la terminal.

El programa ofrece operaciones aritméticas y otras funciones matemáticas, además de permitir consultar y limpiar el historial de operaciones realizadas durante la ejecución.

Su finalidad es practicar los fundamentos de programación en Python, la organización del código en módulos, el manejo de excepciones y el uso de Git y GitHub para el control de versiones.

## Instalación y ejecución

### Requisitos previos

- Tener Python instalado.
- Tener Git instalado para clonar el repositorio.

### 1. Clonar el repositorio

Ejecutar el siguiente comando en la terminal:

```bash
git clone https://github.com/UlisesCor29/Ampliacion-de-la-calculadora.git
```

### 2. Acceder al proyecto

```bash
cd Ampliacion-de-la-calculadora
```

### 3. Ejecutar la calculadora

```bash
cd Calculadora
python calculadora.py
```

También se puede utilizar `python3` en sistemas donde ese sea el comando configurado:

```bash
python3 calculadora.py
```

## Uso del programa

Al ejecutar la calculadora, se mostrará un menú con las operaciones disponibles.

El usuario debe introducir el número correspondiente a la opción que desea realizar y proporcionar los valores solicitados.

El programa también permite:

- Consultar las operaciones realizadas durante la ejecución.
- Limpiar todos los registros del historial.
- Continuar realizando operaciones sin reiniciar el programa.
- Salir de la calculadora mediante la opción correspondiente.
